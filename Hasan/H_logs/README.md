# H_logs: Hasan's dated change log

One file per working day: `YYYY-MM-DD.md`. Each entry records:

- **What** changed and **why** (which approved plan it came from)
- **Files** added / edited / deleted
- **How to verify** (commands, URLs)
- **How to revert** (commit hash or exact steps)

Plans are drafted privately in `Hasan/H_local/implementation/` (gitignored). Only the approved, implemented result is logged here, so the rest of the team can follow each iteration and undo it if needed.
